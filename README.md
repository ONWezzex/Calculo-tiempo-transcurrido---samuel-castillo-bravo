# Cálculo Tiempo Transcurrido

Página web sencilla (HTML, CSS y JavaScript) que calcula el tiempo transcurrido entre una hora inicial y una hora final.

## Cómo funciona

1. Escribe la **hora inicial** (horas, minutos y segundos).
2. Escribe la **hora final**.
3. Presiona **PROCESAR**.
4. El resultado aparece en la sección **Resultado**.

Si la hora final es menor que la inicial, se asume que pasó la medianoche y se suman 24 horas.

## Cómo usarlo

Descarga `index.html` y ábrelo con doble clic en tu navegador. No necesita instalación ni internet.
